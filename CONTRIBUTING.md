# Guia de Contribuicao

Obrigado por se interessar pelo nano-web-agent, agente de IA autonomo para navegadores web com Google Gemini API e Ollama.

Lembre-se de que este projeto possui licenca com restricao comercial (veja LICENSE.md). Contribuicoes de codigo aberto para uso pessoal e academico sao bem-vindas.

## Como contribuir

1. Faca um fork do repositorio.
2. Crie uma branch descritiva para sua alteracao.
3. Envie um Pull Request explicando o que foi mudado e por que.

## Sugestoes de contribuicao

- Novas ferramentas de automacao para o agente.
- Melhorias na extracao da arvore de acessibilidade.
- Suporte a novos provedores de LLM local.

Toda contribuicao construtiva e bem-vinda!
