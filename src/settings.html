📦 Como Instalar o Ollama

Guia rápido de instalação e configuração

▼
ℹ️ O Ollama é gratuito e open-source. Roda modelos de IA localmente na sua máquina.

1. Baixe e instale o Ollama

Acesse ollama.com/download e baixe para Windows, Mac ou Linux.

2. Instale os modelos recomendados

Abra o terminal e execute:

ollama pull qwen2.5:7b
ollama pull llama3.2-vision:11b
ollama pull llama3.1:8b

3. Verifique a instalação

Clique em "Testar Conexão" no card acima. O Ollama deve estar rodando automaticamente após a instalação.

4. Configure o modo

Selecione "Somente Ollama" para usar apenas local, ou "Híbrido" para usar Gemini + Ollama como backup.
