## 📌 Visão Geral
Inspirado por sistemas como *Claude Computer Use*, o **Nano Web Agent** é uma extensão avançada que dá braços e olhos aos modelos de IA dentro do seu navegador. 

Você pode conectar tanto a API da nuvem (Google Gemini) quanto provedores locais (Ollama) para operar o navegador autonomamente: preencher formulários maçantes, realizar varreduras de provas, extrair tabelas e interagir com botões.

## 🚀 Recursos (Superpoderes)
- 🧠 **Agnóstico a LLMs:** Funciona com o Gemini API ou LLMs locais usando Ollama (Gemma, Llama 3, Mistral), reduzindo custos.
- 👁️ **Visão de DOM:** A IA analisa a estrutura da página (content scripts).
- 🕹️ **Ação Autônoma:** Injeta cliques, inputs de teclado e rolagem automática na página, realizando tarefas enfadonhas para você.
- ⚙️ **Configurações Avançadas:** Painel dedicado para injetar prompts de sistema e configurar endpoints locais.
